EcashMesh local API

The routing engine is running. The reference wallet integration is a separate React Native client.

From apps/reference-wallet, run npm ci and npm run web inside the Nix development shell.

Open the Pocket reference client on port 8081

Route evaluation: POST /v1/routes/evaluate

Simulator-only confirmation: POST /v1/simulator/confirm

This local demo does not hold funds or execute payments.
